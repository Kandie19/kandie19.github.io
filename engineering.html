ESCALATION DECISION PATH

AEGIS-style decisioning weighs multiple synthetic signals instead of treating a single detection as the final decision.

Public demonstration only. All values, detections and recommendations are synthetic. No cameras, identities, infrastructure or real-world response systems are connected.

01 / DETECT

Signals become events

Synthetic observations create an event candidate and establish an initial confidence.

02 / CONTEXT

Events gain meaning

Additional synthetic context changes how the event is interpreted and prioritized.

03 / ASSESS

Risk becomes priority

The simulator combines severity, confidence, persistence and context into a synthetic composite risk.

04 / DECIDE

Escalation meets human control

The system presents a decision state and recommendations. The public simulation never executes a real-world response.
