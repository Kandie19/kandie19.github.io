MINIMAL ESCALATION PATH

OPERATOR STATE

MONITOR
No escalation is active. The operator sees a stable environment and continues monitoring.
01 / DETECT

Signals become events

Synthetic camera and activity signals are converted into operator-readable events. Activating a scenario immediately changes the simulated feeds and event stream.

02 / CONTEXT

Events gain meaning

Additional synthetic context changes the assessment of an event, demonstrating why the same signal can produce a different operational priority.

03 / ESCALATE

Priority changes

When a simulated threshold is crossed, the command view progresses through assessment into escalation and visibly presents the changed state.

04 / RESPOND

Human-controlled action

The demonstration stops at an operator decision surface. It does not autonomously control cameras, infrastructure or real-world systems.

Why the Lab Exists

A visitor should be able to understand the operational idea behind AEGIS before asking for implementation details. This simulation demonstrates the core loop—detect → contextualize → assess → escalate → respond—while keeping proprietary architecture, model configuration and production integrations private.
