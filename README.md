# Kelvin Kandie — Executive Portfolio

Elite cyber / command-center portfolio for Kelvin Kandie.

Built with Next.js, React, TypeScript, Framer Motion and Lucide. Static-exported for GitHub Pages.

## Deploy

Push to `main`; the included GitHub Actions workflow builds the static export and deploys it to GitHub Pages.

Public site: `https://kandie19.github.io`

The AEGIS source repository remains private. The portfolio exposes curated architecture and engineering evidence rather than proprietary source.
