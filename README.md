# Kelvin Kandie — Carbon Copy Portfolio

A static, responsive recreation of the supplied Kelvin Kandie portfolio reference.

## Run

Open `index.html` directly in a browser, or serve the folder with any static server.

## Structure

- `index.html` — portfolio markup
- `styles.css` — visual system and responsive layout
- `script.js` — navigation/section highlighting
- `assets/kelvin-portrait.png` — portrait extracted from the supplied reference
